# ⚔️ Jornada do Guerreiro

Um jogo de texto interativo desenvolvido em **Python** para exercitar os conceitos fundamentais de lógica de programação.

## 🚀 Conceitos Praticados
* Manipulação de variáveis e tipos de dados (`int`, `bool`, `string`)
* Entrada e saída de dados (`input` e `print` com formatação)
* Operações aritméticas para controle de status (Vida e Ouro)
* Estruturas condicionais aninhadas (`if`, `elif`, `else`)

## 🎮 Como Jogar
1. Certifique-se de ter o Python instalado na sua máquina.
2. Baixe o arquivo `jornada_do_guerreiro.py`.
3. Abra o terminal na pasta do arquivo e execute:
   ```bash
   python jornada_do_guerreio.py
   ```
4. Digite as opções no terminal para tomar suas decisões e tentar sobreviver!
